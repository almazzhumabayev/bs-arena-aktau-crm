# Статус проекта BS ARENA

Дата статуса: 2026-05-09

## Что уже работает

### Публичный сайт

- Сайт работает локально на `http://localhost:3000`.
- Интерфейс и контент переведены на русский язык.
- Дизайн адаптирован под спортивный комплекс BS ARENA в Актау.
- Работают страницы: главная, о комплексе, услуги, абонементы, расписание, тренеры, мероприятия, аренда и контакты.
- Форма заявки отправляет данные в API.

### CRM вход

- CRM доступна на `http://localhost:3000/admin/login`.
- Вход работает через `POST /api/auth/login`.
- Используются JWT токены.
- Роли: `ADMIN` и `MANAGER`.

### Заявки

- В CRM работает список заявок.
- Работает просмотр деталей заявки.
- Работает смена статуса заявки.
- Работает добавление комментариев к заявке.
- Статусы локализованы: новая, связались, в работе, продано, потеряно.

### Управление контентом

В CRM добавлены рабочие разделы управления существующими сущностями:

- `/admin/services`
- `/admin/memberships`
- `/admin/coaches`
- `/admin/schedule`
- `/admin/events`

Для каждого раздела доступны просмотр списка, создание, редактирование и удаление через существующие API endpoint'ы.

### API

- API работает на `http://localhost:4000/api`.
- Основные публичные endpoint'ы работают:
  - `GET /api/services`
  - `GET /api/memberships`
  - `GET /api/coaches`
  - `GET /api/schedule`
  - `GET /api/events`
- Основные защищенные endpoint'ы CRM работают:
  - `GET /api/leads`
  - `GET /api/leads/:id`
  - `PATCH /api/leads/:id/status`
  - `POST /api/leads/:id/comments`
  - CRUD endpoint'ы для контента.

### База данных

- PostgreSQL работает через Docker Compose.
- Prisma ORM подключена к базе.
- Prisma migrations применяются.
- Схема базы данных стабильна, новые миграции для текущего этапа не требуются.

### Swagger

- Swagger доступен на `http://localhost:4000/docs`.
- Включена Bearer авторизация.
- Документация отражает текущие API endpoint'ы.

### Seed data

- Seed данные переведены на русский язык.
- Контент релевантен BS ARENA в Актау.
- Seed обновляет старые английские записи через `upsert`/обновление существующих записей.

### Backups

- Резервные архивы проекта были созданы до последних этапов доработок.
- Перед production-деплоем нужно настроить регулярные бэкапы базы PostgreSQL и файлов окружения.

## Текущий статус

MVP готов к демонстрации локально через Docker Compose. Следующий крупный этап - подготовка production-инфраструктуры и деплой на VPS.
