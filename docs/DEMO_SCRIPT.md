# Сценарий демонстрации BS ARENA Website + CRM MVP

Этот сценарий помогает показать клиенту текущую рабочую версию: публичный сайт, отправку заявки, обработку лида в CRM и управление контентом. Перед демо нужно убедиться, что сайт, API и база данных запущены.

## Цель демо

Показать, что MVP уже закрывает основной рабочий поток:

1. Клиент видит публичный сайт BS ARENA.
2. Посетитель оставляет заявку.
3. Менеджер видит заявку в CRM.
4. Менеджер меняет статус заявки и добавляет комментарий.
5. Администратор может управлять контентом сайта через CRM.

## Подготовка перед демонстрацией

| Шаг | Что проверить | Ожидаемый результат |
| --- | --- | --- |
| 1 | Открыть публичный сайт | Главная страница загружается без ошибок |
| 2 | Открыть страницу входа в CRM | Форма входа доступна |
| 3 | Проверить тестовый аккаунт администратора | Вход в CRM проходит успешно |
| 4 | Проверить API и базу данных | Заявки и контент отображаются в CRM |
| 5 | Подготовить тестовые данные для заявки | Есть имя, телефон и комментарий для отправки |

## Что показать в CRM

| Раздел CRM | Что показать | Зачем это важно |
| --- | --- | --- |
| Заявки | Список лидов, карточка лида, смена статуса | Показывает рабочий процесс менеджера |
| Комментарии | Добавление заметки к заявке | Показывает историю коммуникации с клиентом |
| Услуги | Список, создание, редактирование, удаление | Показывает управление разделом услуг на сайте |
| Абонементы | Список тарифов и редактирование данных | Показывает возможность менять предложения без разработчика |
| Тренеры | Список тренеров и карточки | Показывает управление командой и профилями |
| Расписание | Список занятий и редактирование | Показывает управление актуальным графиком |
| Мероприятия | Список событий и редактирование | Показывает управление турнирами, акциями и событиями |

## Важные акценты для клиента

- Это MVP, уже работающий end-to-end: сайт, API, база данных и CRM связаны между собой.
- Реальный контент пока не загружен, поэтому текущие тексты и данные используются только для демонстрации.
- Код, API и структура базы на этом этапе не меняются при добавлении клиентского контента через CRM.
- После получения материалов можно наполнить сайт реальными данными и подготовить production-запуск.
