## Рекомендации к материалам

- Тексты лучше предоставить в одном документе с понятной структурой по разделам.
- Фото желательно передавать отдельной папкой, без сильного сжатия и без водяных знаков.
- Логотип лучше предоставить в SVG, PNG или PDF.
- Для цен и расписания важно указать, какие данные можно публиковать на сайте, а какие нужны только для внутреннего использования.
- Если часть контента еще не готова, можно сначала передать обязательные поля, а дополнительные материалы добавить позже через CRM.
